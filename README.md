# 📚 Startpage - Modern Browser Start Page

A beautiful, customizable start page with bookmark management and Supabase integration.

## ✨ Features

- **🔍 Multi-Engine Search**: Search with SearXNG, Google, DuckDuckGo, or YouTube
- **⌨️ Keyboard Shortcuts**: Quick access with chord system (2-letter combinations)
- **🌙 Dark/Light Theme**: Toggle between themes with persistent storage
- **💾 Local Storage**: Bookmarks saved locally for offline access
- **☁️ Supabase Sync**: Cloud synchronization for bookmarks across devices
- **📱 Responsive Design**: Works perfectly on desktop and mobile

## 🚀 Quick Start

1. **Download** the `index.html` file
2. **Open** in your web browser
3. **Configure** Supabase (optional) for cloud sync

## 🎯 Usage

### Search
- Type in the search box and press Enter
- Use Alt + A/S/D/F to quickly switch search engines
- Press `/` to focus the search box

### Bookmarks
- **Add**: Click "➕ Add Bookmark" button
- **Access**: Type the 2-letter chord (e.g., "HN" for Hacker News)
- **Sync**: Use "🔄 Sync with Supabase" to save to cloud
- **Load**: Use "📥 Load from Supabase" to restore from cloud

### Keyboard Shortcuts
- `/` - Focus search box
- `Alt + A` - Search with SearXNG
- `Alt + S` - Search with Google  
- `Alt + D` - Search with DuckDuckGo
- `Alt + F` - Search with YouTube
- `2-letter chord` - Open bookmark (e.g., "GH" for GitHub)

## 🛠️ Customization

### Adding Search Engines
Edit the `searchEngines` object in the JavaScript:

```javascript
const searchEngines = {
    searxng: 'https://search.fmhy.net/search?q=',
    google: 'https://www.google.com/search?q=',
    // Add your custom search engine
    custom: 'https://example.com/search?q='
};
```

### Modifying Default Bookmarks
Edit the `defaultBookmarks` array:

```javascript
const defaultBookmarks = [
    { title: 'Your Site', url: 'https://yoursite.com', chord: 'YS' },
    // Add more bookmarks...
];
```

## 🔧 Technical Details

### Database Schema
The Supabase table structure:

```sql
CREATE TABLE bookmarks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id TEXT NOT NULL DEFAULT 'default_user',
  bookmarks_data JSONB NOT NULL DEFAULT '[]'::jsonb,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### API Endpoints
- `GET /rest/v1/bookmarks?user_id=eq.default_user` - Load bookmarks
- `POST /rest/v1/bookmarks` - Sync bookmarks (with upsert)

### Browser Compatibility
- Modern browsers with ES6+ support
- Local Storage API
- Fetch API

## 🐛 Troubleshooting

### Supabase Connection Issues
1. Verify your URL and API key are correct
2. Check that RLS is disabled for the bookmarks table
3. Ensure the table exists and has the correct schema

### Bookmarks Not Saving
1. Check browser console for errors
2. Verify localStorage is enabled
3. Try the sync function to test Supabase connection

### Search Not Working
1. Verify search engine URLs are accessible
2. Check for ad blockers that might interfere
3. Ensure JavaScript is enabled
